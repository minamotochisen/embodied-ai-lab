# 具身智能实操工作区

《具身智能前沿论文知识库》配套的动手实操环境,记录见知识库 [04-实操记录/SmolVLA上手实操](https://github.com/minamotochisen/embodied-ai-knowledge-base)。

## 目录

- `scripts/` — 实操脚本(推理验证、checkpoint 迁移)
- `models/`、`hf_cache/`、`outputs/` — 大文件,不入库,按笔记命令重新下载/训练即可

## 环境

conda 环境 `embodied`:Python 3.10 + torch 2.10.0+cu126 + lerobot 0.4.4,详见知识库实操记录第二节。
